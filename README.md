# WSoft Lite

Sistema de gestión comercial para pequeños negocios y emprendimientos.

WSoft Lite es una aplicación de escritorio desarrollada en Python para facilitar la gestión de productos, inventario, clientes, proveedores, ventas y compras desde una interfaz sencilla y práctica.

## Características

- Gestión de productos e inventario
- Control de stock
- Gestión de clientes
- Gestión de proveedores
- Gestión de vendedores
- Punto de venta (POS)
- Registro de compras
- Kardex y movimientos de inventario
- Reportes
- Exportación de información a Excel
- Generación de documentos PDF
- Copias de seguridad y restauración
- Sistema de licencias
- Modo DEMO para evaluación

## Tecnologías

- Python
- CustomTkinter
- Tkinter
- SQLite
- ReportLab
- Pandas
- OpenPyXL
- PyInstaller
